# TCP-клиент и сервер

Исходники разделены на три каталога:

- `client/` — точка входа `ClientMain.cpp` и TCP-клиент `TcpClient.*`.
- `server/` — точка входа `ServerMain.cpp`, сервер `TcpServer.*`, сессия подключения `ClientSession.*` и заготовка `UserDirectoryDatabase.*`.
- `shared/` — библиотека `tcp_common`: чтение файлов, конфигурация подключения, разбор запросов и сериализация команды регистрации.

`EndpointConfig.json` задаёт адрес и порт. Имена исполняемых файлов и аргументы запуска сохранены.

Для сборки нужны CMake 3.16+, компилятор C++20 и Boost.JSON:

```sh
cmake -S . -B build
cmake --build build
```

Программы и копия конфигурации помещаются в `build/bin/`. Отдельный каталог `bin/` исключает конфликт с каталогами исходников даже при сборке в корне проекта.

Запуск из корня проекта в отдельных терминалах:

```sh
./build/bin/server build/bin/EndpointConfig.json
./build/bin/client build/bin/EndpointConfig.json
```

Клиент принимает команду `/REGISTER`, затем логин и пароль.

В исходном коде остаются незавершённые участки: в `server/ClientSession.cpp` строка `boost::json::object;` препятствует сборке, а текст ответа не заполняется. `server/UserDirectoryDatabase.cpp` не включён в сборку: в нём не объявлен `reader` и отсутствует возвращаемый результат. Эти участки оставлены без изменения логики.
